# Salvation Ministries Youth Convention Timer

![Salvation Ministries](img.jpg)

A stage countdown timer built for the Salvation Ministries Obiri-ikweree youth convention, so sessions, can be timed on a small screen on Altar keeping up with HQ.

Set a time, hit Start, and go fullscreen. Runs past zero into red, pulsing overtime so the room knows time's up. Tap the logo in fullscreen to bring the controls back if you need to reset or set a new time.
