# Salvation Ministries — Youth Convention Timer

A simple countdown timer for the youth convention stage. Open it, set a time, and go.

## Files

Keep these two files together in the same folder:

- `index.html` — the app
- `img.jpg` — the logo shown at the top

## How to use it

1. Open `index.html` in any browser.
2. Pick a preset, or type a custom time and hit **Set**, then **Start**.
3. Tap **Fullscreen** (or press `F`) to project it — this hides the buttons and fills the screen with just the logo, clock, and timer.
4. While in fullscreen, **tap the logo** to bring the controls back if you need to set a new time or restart. Tap it again to hide them.

## Shortcuts

- `Space` — Start / Pause
- `R` — Reset
- `F` — Fullscreen

## Customizing

- Presets: edit the `presets` list in the script.
- Colors: edit the `:root` variables at the top of the `<style>` section.
- Logo: replace `img.jpg` with your own image (same filename).
